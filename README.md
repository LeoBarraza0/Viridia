# Viridia

Activo digital de Arquitectura Empresarial de VIRIDIA S.A.S. BIC (compañía ficticia de uso académico).
Proyecto final de Arquitectura Empresarial, Universidad Libre, 2026.

**Sitio publicado:** https://leobarraza0.github.io/Viridia/

Recorre las seis capas de la arquitectura (estrategia, procesos, información, aplicaciones, tecnología y
transformación) y simula el análisis de las facturas, la línea base y el cobro por ahorro verificado.

Es un sitio estático: también se abre sin internet con doble clic en `index.html`.
La documentación completa (pantallas, simulador, mantenimiento y publicación) está en [LEEME.md](LEEME.md).
